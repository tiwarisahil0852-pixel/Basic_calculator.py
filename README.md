# Python Calculator

A simple, menu-driven calculator built with Python. This project is beginner-friendly and demonstrates basic Python concepts such as loops, conditional statements, user input, type conversion, and exception handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Prevents division by zero
- Handles invalid number input
- Repeats until the user chooses Exit

## Requirements

- Python 3.x

No external libraries are required.

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python calculator.py
```

If your system uses `python3`, run:

```bash
python3 calculator.py
```

## How to Use

When the program starts, choose an operation:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

Enter two numbers when prompted. The calculator will display the result.
